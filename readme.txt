Install your favorite WordPress plugins with one click. No more repetitive plugin installations!

== Description ==

QuickStart Plugin allows you to install a predefined set of WordPress plugins with just one click. Perfect for developers and site builders who frequently set up new WordPress installations and want to save time by avoiding repetitive plugin installations.

== Features ==

* One-click installation of popular WordPress plugins
* Bulk install and activate all plugins
* Add your own custom plugins to the list
* Clean, intuitive interface
* Currently includes:
  * Elementor
  * EWWW Image Optimizer
  * Easy Code Manager
  * All-in-One WP Migration

== Installation ==

1. Upload the `quickstart-plugin` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Tools > QuickStart to start installing plugins

== Frequently Asked Questions ==

= Can I add my own plugins to the list? =

Yes! You can add custom plugins in the Settings page (Tools > QuickStart Settings).

= What permissions do I need to use this plugin? =

You need to have the `install_plugins` and `activate_plugins` capabilities, which typically means you need to be an administrator.
