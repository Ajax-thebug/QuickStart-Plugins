# QuickStart-Plugins
Quickstart Plugins is a time-saving tool designed for WordPress developers and site builders who regularly install the same set of plugins on new WordPress installations.

**Key Features:**

Pre-install your favorite plugins with a single click
Add and remove plugins from your installation list
Option to automatically install plugins when the Bulk Plugin Installer activates
Simple, clean interface integrated into WordPress settings

**Ideal For:**

Web developers creating multiple client sites
Agency workflows that require consistent plugin setups
Website maintenance professionals
Anyone who regularly sets up new WordPress installations

**How It Works:**
The plugin provides a straightforward admin interface to manage your list of preferred plugins. When activated, it uses the WordPress Plugin API to fetch and install your chosen plugins directly from the WordPress.org repository.

**Requirements:**

WordPress 5.0 or higher
PHP 7.0 or higher
Admin privileges on your WordPress installation
